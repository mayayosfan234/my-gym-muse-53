# GymTrack — עברית מלאה, RTL, פיצ'רים ומובייל

אני חייב את האישור שלך (כפתור Approve) כדי להתחיל לכתוב קוד — זו מגבלת מערכת, לא בקשה לעוד החלטות. אשר, ואבצע את כל הרשימה ברצף בלי לעצור.

בדקתי: ה-repo `mayayosfan234/my-gym-muse-53` נגיש ומכיל בדיוק את הקוד שנמצא כאן (אותם מסכים, store, נתונים). לכן ממשיכים מהקוד הקיים — בלי בנייה מחדש. ה-build תקין כרגע.

## 1. עברית ו-RTL
`lang="he"` + `dir="rtl"` ברמת האפליקציה, גופן Heebo/Assistant, והחלפת כל מחלקות הכיוון הקשיחות (`ml-`,`mr-`,`left-`,`right-`,`text-left`) בלוגיות (`ms-`,`me-`,`start-`,`end-`,`text-start`). תרגום מלא של כל טקסט בממשק: בית, תוכניות, בונה אימון, אימון פעיל, ספריית תרגילים, היסטוריה, תזונה, הודעות, מצבים ריקים, כפתורים ו-placeholders. תאריכים ב-`he-IL` עם "היום / אתמול / לפני 3 ימים / השבוע".

## 2. אימונים
- תוכנית התחלתית: פלג גוף תחתון 1, פלג גוף עליון 1, פלג גוף תחתון 2, פלג גוף עליון 2 — ניתנת לעריכה מלאה.
- משקל נפרד לכל סט (גם בבונה וגם באימון פעיל).
- טווח חזרות (8–10) + רישום חזרות בפועל לכל סט.
- Superset רק בבחירה מפורשת: יצירה, בחירת תרגילים, ביטול, סימון ויזואלי ברור.
- Drop Set במודל הנתונים: הפעלה לסט, שלבי הורדת משקל, שמירה בהיסטוריה.
- חימום: תיקון המגבלה של ספרה אחת — מאפשר 10, 15, 30 וכו'.
- לחיצה על שם תרגיל באימון פעיל פותחת גיליון עם כרטיס התרגיל (שריר, ציוד, תיאור, הדגשים, הוראות, הערות) בלי לאבד את מצב האימון.
- הערות נשמרות ונטענות בכל מקום (תרגיל, סט, אימון, תוכנית).

## 3. תרגילים
רשימת קבוצות שרירים מורחבת בעברית (חזה, גב, כתפיים, יד קדמית/אחורית, אמות, בטן, אלכסונים, זוקפי גב, ישבן, ארבע ראשי, המסטרינג, תאומים, מקרבים, מרחיקים, מכופפי ירך, צוואר ועוד), בחירה מרובה, ואפשרות "אחר" עם שם שריר מותאם אישית שנשמר בנתונים.

## 4. תזונה
- מאגר מזון ישראלי מורחב: מוצרי חלב, גבינות, יוגורטים, קוטג', ביצים, בשר, עוף, דגים, טונה, קטניות, אורז, פסטה, לחמים, פיתות, דגני בוקר, פירות, ירקות, אגוזים, חמאת בוטנים, טחינה, רטבים, חטיפים ומוצרי חלבון — עם מבנה שמאפשר הוספת מוצרים בקלות.
- ביצה S/M/L עם ערכים נפרדים; גבינות לפי אחוז שומן (5%/9%/15%/28%); אדממה עם ערכים ל-100 גרם.
- חיפוש אמין (התאמה חלקית, התעלמות מניקוד/רווחים).
- החלפת מוצר לפי קלוריות: חישוב מתמטי של הכמות בגרמים שנותנת את אותן קלוריות, כולל תצוגת המקרו החדש. אבדוק על ביצה, אורז, עוף, גבינה, יוגורט, לחם, פרי ואדממה.
- תיקון באג פתיחת דף מזון באמצע/תחתית הדף — גלילה לראש הדף בכל ניווט, ברמת ה-router.

## 5. עיצוב ומובייל
פלטת פסטל עקבית (Sage, Cream, Soft Pink, Off-white), כרטיסים רכים וצללים עדינים. תכנון mobile-first לאייפון: ללא גלילה אופקית, בלי אלמנטים שחורגים, כפתורים ושדות בגודל אצבע, טיפול ב-safe area, מקלדת שלא מסתירה שדות, וניווט תחתון שלא מכסה תוכן (בית / תוכניות / תרגילים / תזונה / היסטוריה, ב-RTL). תחושת אפליקציה: סטיקי headers, מעברים עדינים, פקדי מגע.

## 6. PWA
manifest, שם אפליקציה, אייקון, theme color, standalone ו-metadata ל-iOS — ללא service worker שעלול לשבור את ה-preview.

## 7. נתונים, בדיקות ומסירה
- Migration בטוח: רק הוספת שדות, backward compatibility, בלי מחיקת נתונים קיימים או היסטוריה.
- בדיקה בפועל בדפדפן במסך אייפון צר על כל הזרימות ברשימה שלך, ותיקון מה שנשבר.
- הרצת build ותיקון כל שגיאות TypeScript/lint/runtime.
- יצירת `PROJECT_HANDOFF.md` כולל סקירה, tech stack, התקנה, ארכיטקטורה, store, מערכות אימון/תרגילים/תזונה/החלפת מזון/היסטוריה, RTL, מובייל, PWA, פיצ'רים שהושלמו, מגבלות ידועות, ו-prompt מוכן להעתקה ל-AI אחר.
- דחיפה ל-GitHub: הסנכרון ל-`mayayosfan234/my-gym-muse-53` מתבצע אוטומטית דרך חיבור ה-GitHub של Lovable אחרי שהשינויים נשמרים. אאמת שהקבצים עודכנו שם; אם החיבור לא פעיל אדווח לך בדיוק מה לעשות (Plus (+) → GitHub).
