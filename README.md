# My Gym Companion

I want to build a personal gym workout tracking web app, similar in concept to Hevy or Strong, but simpler and completely customizable.

The app is for personal use.

I want an Exercise Library where I can add, edit and delete exercises.

Each exercise should have:

Exercise name

Muscle group

Equipment

Description

Video

Images

Personal notes

I also want to create workouts from my exercise library.

Each workout should contain exercises, and for every exercise I should be able to set:

Sets

Reps

Weight

Rest time

Notes

I want to be able to easily change the weight and reps during a workout.

I also want the app to save my workout history, so I can see what weight, reps and sets I used in previous workouts.

I want a clean, modern gym-app design that works extremely well on mobile phones.

The main screens should be:

Dashboard

Exercise Library

My Workouts

Workout Builder

Workout History

Exercise Details

Use a modern, minimal interface with large buttons and easy navigation on a phone.

For now, focus on building the complete UI and functionality. We will refine the database, authentication and other details later.
